## ⭐ Featured Project: Data Cleaning, Amazon Sales Dataset

Turned a raw, messy Amazon India product dataset into an analysis-ready one:

- 🧹 Converted text prices, discounts and ratings (₹, commas, %) into numeric types
- 🩹 Filled missing values with the median, chosen because the data is right-skewed
- 🗑️ Removed 114 repeated product IDs (**1,465 → 1,351 rows**)
- 🗂️ Split the category hierarchy into main, sub and leaf categories
- 🔎 Checked outliers with the IQR method and documented a keep/remove decision for each column
- 📊 Added 20 charts and written observations on pricing, discounts and ratings
